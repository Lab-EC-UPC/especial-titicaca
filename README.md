Proyecto Titicaca — Especial Periodístico

Este proyecto consiste en el desarrollo de un especial web interactivo enfocado en la cobertura periodística de la región del Lago Titicaca.

El objetivo es presentar información de manera visual, narrativa e interactiva, combinando contenido editorial con desarrollo web moderno.
